# Арбітражний бот DEX ↔ CEX

Шукає різницю цін між централізованими біржами (Binance, Bybit, OKX, Gate, MEXC) і DEX у мережах BSC, Arbitrum, Base та Solana. Сигнали надсилає в Telegram і показує в React-панелі. **Сам нічого не купує й не продає.**

## Як це працює

1. Раз на 30 хв бот завантажує з кожної CEX список ринків до USDT, мережі депозиту/виводу кожного токена, адреси контрактів і статус «депозит/вивід відкритий».
2. Кожні 30 с бере ціни: CEX через [ccxt](https://github.com/ccxt/ccxt), DEX через [DexScreener](https://docs.dexscreener.com/api/reference) (найліквідніший пул токена). Токен на DEX шукається **за адресою контракту від самої біржі**, а не за тікером, тому підробки з тим самим тікером не потрапляють.
3. Рахує чистий прибуток на заданий обсяг (за замовчуванням $500) в обидва боки:
   - **DEX → CEX**: своп на DEX (комісія + прослизання пулу) → переказ на біржу (газ) → продаж по стакану CEX (комісія тейкера).
   - **CEX → DEX**: купівля по стакану CEX → вивід (комісія виводу біржі) → продаж на DEX.
4. Зв'язки, що дають більше `minProfitPct` (1,5%), перевіряються по реальному стакану CEX і йдуть у Telegram. Та сама зв'язка повторюється не частіше ніж раз на 15 хв (або раніше, якщо прибуток виріс у 1,5 раза).

## Запуск на вашому комп'ютері

Потрібен [Node.js](https://nodejs.org) 22 або новіший.

```bash
npm install
cp .env.example .env     # заповніть Telegram і (бажано) ключі бірж
npm run dev              # сканер + панель
```

Панель відкриється на http://localhost:5173. Для постійної роботи без режиму розробки: `npm start` (панель буде на http://localhost:8787).

### Telegram
1. Напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → скопіюйте токен у `TELEGRAM_BOT_TOKEN`.
2. Напишіть своєму боту будь-що, потім дізнайтеся свій chat id через [@userinfobot](https://t.me/userinfobot) і вставте в `TELEGRAM_CHAT_ID`.
3. У панелі: «Налаштування» → «Тест Telegram».

### Ключі бірж (лише на читання!)
Binance, Bybit, OKX і MEXC віддають статус депозиту/виводу та адреси контрактів тільки з API-ключем. Без ключа ця біржа знайде мало токенів або жодного (див. вкладку «Статус джерел»). Gate віддає ці дані без ключа.

Створюйте ключ **тільки з правом читання**, без торгівлі й виводу, і за можливості з прив'язкою до вашої IP-адреси.

## Налаштування
Усе змінюється в панелі й зберігається в `scanner/data/config.json`: біржі, мережі, обсяг угоди, мінімальний прибуток, комісії, газ, ліквідність, токени вручну.

## Обмеження
- Прослизання на DEX оцінюється за моделлю x·y=k з половиною ліквідності пулу. Для Uniswap v3 / PancakeSwap v3 це консервативна оцінка.
- Ціни DexScreener оновлюються з невеликою затримкою. Перед угодою перевіряйте ціну вручну.
- Переказ між біржею і мережею займає від секунд до десятків хвилин, і за цей час спред може зникнути.
